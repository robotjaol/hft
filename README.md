# Jane Street Open Source Snapshot

- **Source:** [Jane Street GitHub](https://github.com/janestreet)
- **Primary Language:** OCaml
- **License:** MIT (refer to individual `LICENSE.md` files)

## Key Repositories

| Repository | Description |
|---|---|
| `base` | Core standard library |
| `core` | Extended standard library |
| `core_kernel` | Portable core components |
| `stdio` | Input and output operations |
| `incremental` | Incremental computation |
| `async` | Asynchronous and concurrent programming |
| `ppx_jane` | Collection of OCaml preprocessor extensions |
